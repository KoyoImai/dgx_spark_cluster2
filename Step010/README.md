# ステップ10
NCCL testによる通信速度のテストを実行する．

## 前置き
ステップ6〜ステップ9までで，QSFPスイッチによる4台接続を行ってきたが，速度が著しく遅いという現象が発生していた．
現在でも原因は不明だが，QSFPケーブルの差し替え（スイッチ経由からQSFPケーブル直接接続の切り替え）によって速度が低下するということが判明した．
DGX Spark自体を再起動すれば速度は元に戻るが，その後QSFPケーブルの差し替えを行うを速度が低下する．
根本的な原因解明と対策はまだできていないあ，一旦この問題は傍に置いておいて，NCCL testによる速度調査を行う．
